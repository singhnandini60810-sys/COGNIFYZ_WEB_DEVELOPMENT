## About the Internship Tasks

The Cognifyz Web Development Internship task structure contains three levels of increasing difficulty. For this project, **Level 1 and Level 3** were selected and completed.

The projects focus on fundamental and practical web-development concepts including HTML, CSS, JavaScript, responsive design, interactive components, image manipulation, and landing-page development.
